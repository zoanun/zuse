# S2.1 — 小模型生成会话标题 设计

> **日期**: 2026-06-26
> **所属**: S2（会话列表侧边栏）的增强；让列表里的标题由小模型生成而非截断首句
> **前置**: S2 已实现（标题三态：manual rename / deriveTitle）

---

## 1. 目标

会话标题不再是"截断第一句话",而是用一个**廉价小模型**根据首条用户消息生成简洁标题。没配小模型 / 调用失败时**回退**到原来的截断逻辑(`deriveTitle`),绝不阻断主流程。

**已定决策**：
- 新增 `settings.smallModel`（`<provider>/<model>`）；缺省=不启用→回退截断。
- **消息一发出(submit/turn-start)就生成一次**(不等助手回复)并钉住，后续不重生；**手动改名仍优先**。
- 生成完通过 `title-changed` 事件**实时推前端**自动更新(不用刷新)。
- 配置：`smallModel = siliconflow/Qwen/Qwen2.5-7B-Instruct`（免费小模型，纯 instruct）。

## 2. core 改动
- `ResolvedSettings.smallModel?: string` + `RawSettings.smallModel` + mergeLayers 透传。
- `resolveSmallModelSelection(settings): ModelSelection | null`——仅在第一个 `/` 切分（模型名里的 `/` 合法，如 `siliconflow/Qwen/Qwen2.5-7B-Instruct`）；未配置返回 null。
- `title.ts`：`generateSessionTitle(client, model, firstUserText, signal?): Promise<string|null>`——单次请求（无工具、`max_tokens=48`），收集 text-delta；清洗（去包裹引号 / `标题:`前缀 / 句末标点、取首行、截断 60 字）；空/错/空输入→null。镜像 `summarizeForCompaction` 的健壮性模式。

## 3. server 改动
- 协议 `SessionEvent += { type:'title-changed'; title }`。
- `SessionManagerOptions += titleClient?; titleModel?; titleAlreadySet?`；`SessionManager`：私有 `titleSettled`(由 titleAlreadySet 初始化)/`titlePending`；`submit()` 在 emit turn-start 后、非 resend 时调 `kickTitleGeneration(text)`——用**这条消息的文本**(不等回复、与回合并行)调 core helper,成功则置 titleSettled 并 emit `title-changed`(只一次,失败留 false 可下条重试)。
- `createSession`：`resolveSmallModelSelection` 有值且其 provider 有 key → 建 titleClient（任意失败仅告警、降级无小模型）;透传 titleAlreadySet;注入了 fake client 的离线测试不建真实 titleClient。
- `sessionStore.SessionRecord += titleGenerated?: boolean`。
- `SessionService`：新增 `generatedTitles` map；
  - 订阅到 `title-changed` → 若无 manual、未删除 → `generatedTitles.set` 并 persist。
  - 标题优先级：`forcedTitle ?? manualTitles ?? generatedTitles ?? deriveTitle`；记录写 `titleGenerated` 标记。
  - `getOrLoad` 从盘 re-seed：`titleManual` 优先，否则 `titleGenerated`→`generatedTitles`；并传 `titleAlreadySet = 非空会话 || titleManual || titleGenerated`（重启/续聊不重生）。
  - `rename` 清掉 `generatedTitles`（手动覆盖生成）；`delete` 清 `generatedTitles`。
- wsServer 原样转发 `title-changed`（无需特殊处理）。

## 4. 前端
- store `onMessage` 收到 `title-changed` → **直接用事件里的 title 就地更新**当前会话那一行(不重新 GET——GET 会和服务端异步 persist 抢跑、可能读到旧标题;事件值才是 UI 权威)。turn-end 仍 `refreshSessions`(补 messageCount/回退标题)。reducer 对未知事件 `default` 忽略,不破。

## 5. 已知限制 / follow-up
- 压缩摘要(`summarizeForCompaction`)目前仍用主模型；可复用 smallModel 省 token（留 follow-up）。
- 非聊天小模型（推理类）不宜做标题；用户已选纯 instruct 的 Qwen2.5-7B。

## 6. 测试
- core `title.test.ts`(10)：生成/清洗（引号·前缀·句末标点·多行取首行）/错误→null/空回复→null/空输入不调用模型/超长截断；`resolveSmallModelSelection` null·首斜杠切分·裸串。
- server `SessionService.test.ts`：消息一发即生成并钉住(titleGenerated)、不重生(计调用次数)、emit title-changed 携带标题、手动改名覆盖(titleManual=true,titleGenerated=false)、`getOrLoad` 恢复非空/titleGenerated 不重生、无小模型→不生成回退 deriveTitle。
- 全程离线（注入 fake titleClient），不打真实网络。core+server+web 全绿（仅既有 live-API 环境性失败无关）。
