# S2.1 — 小模型生成会话标题 设计

> **日期**: 2026-06-26
> **所属**: S2（会话列表侧边栏）的增强；让列表里的标题由小模型生成而非截断首句
> **前置**: S2 已实现（标题三态：manual rename / deriveTitle）

---

## 1. 目标

会话标题不再是"截断第一句话",而是用一个**廉价小模型**根据首条用户消息生成简洁标题。没配小模型 / 调用失败时**回退**到原来的截断逻辑(`deriveTitle`),绝不阻断主流程。

**已定决策**：
- 新增 `settings.smallModel`（`<provider>/<model>`）；缺省=不启用→回退截断。
- **首个回合(turn-end)后生成一次**并钉住，后续不重生；**手动改名仍优先**。
- 配置：`smallModel = siliconflow/Qwen/Qwen2.5-7B-Instruct`（免费小模型，纯 instruct）。

## 2. core 改动
- `ResolvedSettings.smallModel?: string` + `RawSettings.smallModel` + mergeLayers 透传。
- `resolveSmallModelSelection(settings): ModelSelection | null`——仅在第一个 `/` 切分（模型名里的 `/` 合法，如 `siliconflow/Qwen/Qwen2.5-7B-Instruct`）；未配置返回 null。
- `title.ts`：`generateSessionTitle(client, model, firstUserText, signal?): Promise<string|null>`——单次请求（无工具、`max_tokens=48`），收集 text-delta；清洗（去包裹引号 / `标题:`前缀 / 句末标点、取首行、截断 60 字）；空/错/空输入→null。镜像 `summarizeForCompaction` 的健壮性模式。

## 3. server 改动
- `SessionManagerOptions += titleClient?: ModelClient; titleModel?: string`；`SessionManager.generateTitle()`：无 titleClient/无用户文本→null，否则取首条用户消息文本（剥时间戳前缀）调 core helper。
- `createSession`：`resolveSmallModelSelection` 有值且其 provider 有 key → 建 titleClient（任意失败仅告警、降级无小模型）；注入了 fake client 的离线测试不建真实 titleClient。
- `sessionStore.SessionRecord += titleGenerated?: boolean`。
- `SessionService`：新增 `generatedTitles` map + `titlePending` set；
  - turn-end 时除常规 autosave 外，`maybeGenerateTitle()` 调一次 `mgr.generateTitle()`，成功则入 `generatedTitles` 并 persist；`titlePending` 保证只生成一次。
  - 标题优先级：`forcedTitle ?? manualTitles ?? generatedTitles ?? deriveTitle`；记录写 `titleGenerated` 标记。
  - `getOrLoad` 从盘 re-seed：`titleManual` 优先，否则 `titleGenerated`→`generatedTitles`（重启不重生）。
  - `rename` 清掉 `generatedTitles`（手动覆盖生成）；`delete` 清 `generatedTitles`/`titlePending`。

## 4. 已知限制 / follow-up
- **生成的标题不会实时推到前端**：生成在首个 turn-end 后异步完成并落盘，前端要到下次 `refreshSessions`（下个 turn-end / 切换 / 刷新）才看到。要实时更新需加一个 `title-changed` 协议事件 + WS 转发 + 前端 reducer 处理（留 follow-up）。
- 压缩摘要(`summarizeForCompaction`)目前仍用主模型；可复用 smallModel 省 token（留 follow-up）。
- 非聊天小模型（推理类）不宜做标题；用户已选纯 instruct 的 Qwen2.5-7B。

## 5. 测试
- core `title.test.ts`：生成/清洗（引号·前缀·句末标点·多行取首行）/错误→null/空回复→null/空输入不调用模型/超长截断；`resolveSmallModelSelection` null·首斜杠切分·裸串。
- server `SessionService.test.ts`：首回合生成并钉住(titleGenerated)、不重生(计调用次数)、手动改名覆盖(titleManual=true,titleGenerated=false)、`getOrLoad` 恢复 titleGenerated 不重生、无小模型时 `generateTitle()` 返回 null。
- 全程离线（注入 fake titleClient），不打真实网络。core+server 全绿（仅既有 live-API 环境性失败无关）。
