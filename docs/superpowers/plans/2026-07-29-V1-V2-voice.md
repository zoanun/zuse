# V1 + V2 语音交互 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Composer 里录音 → 转写填进输入框（V1）；助手消息一键朗读（V2）。未配置对应模型时按钮自动隐藏。

**Architecture:** `sttModel`/`ttsModel` 走与 `imageModel` 同款的 `provider/model` 解析；服务端 `VoiceService` 用已在依赖里的 `openai` SDK 打 OpenAI 兼容的 `/audio/transcriptions` 与 `/audio/speech`；三个 `/api/voice*` 路由；前端 Composer 加麦克风、Message 加朗读按钮，按 `GET /api/voice` 的能力探测显隐。

**Tech Stack:** TypeScript、`openai` SDK（已有）、浏览器 `MediaRecorder` / `Audio`、vitest。**零新依赖。**

**Spec:** `docs/superpowers/specs/2026-07-29-V1-V2-voice-design.md`

**分支**：从 master 切 `v1-v2-voice`。

**约束**：不引 `@zuse/core` 值进 web（只 `import type` protocol）；server 无 test 脚本 → 根 vitest；web 测试包内跑；`noUncheckedIndexedAccess: true`。

**既知环境性失败（勿当回归）**：`packages/tools/src/bash.test.ts` 9 个（spawned shell PATH）；`packages/server` 的 `wsServer.test.ts`/`SessionService.test.ts` 在本机高 node 进程负载下超时（已在 master 同条件复现），隔离重跑取证。

**契约**（spec §4.1）：

```ts
export class VoiceNotConfiguredError extends Error {}      // → 路由 400
export class UnsupportedAudioTypeError extends Error {}    // → 路由 415

export interface VoiceServiceDeps {
  /** 注入用:测试传假 client,全程离线。缺省按 settings 现建 OpenAI client。 */
  makeClient?: (baseURL: string, apiKey: string) => AudioClient
  /** 注入用:测试传假 settings。缺省 loadSettings()。 */
  loadSettings?: () => ResolvedSettings
}

/** 只用到 openai SDK 的音频子集 —— 便于测试注入。 */
export interface AudioClient {
  audio: {
    transcriptions: { create(args: { file: unknown; model: string; response_format: 'text' }): Promise<unknown> }
    speech: { create(args: { model: string; voice: string; input: string; response_format: 'mp3' }): Promise<{ arrayBuffer(): Promise<ArrayBuffer> }> }
  }
}

export class VoiceService {
  constructor(deps?: VoiceServiceDeps)
  capabilities(): { stt: boolean; tts: boolean }
  transcribe(audio: Buffer, mimeType: string): Promise<string>
  speak(text: string): Promise<{ audio: Buffer; contentType: string; truncated: boolean }>
}
```

要点：
- `MIME_EXT`：`audio/webm`→`webm`、`audio/mp4`→`m4a`、`audio/mpeg`→`mp3`、`audio/wav`/`audio/x-wav`→`wav`、`audio/ogg`→`ogg`。带参数的 mime（`audio/webm;codecs=opus`）先按 `;` 截断再查表。表里没有 → `UnsupportedAudioTypeError`（不瞎猜扩展名）。
- 解析出的 provider 若 `protocol !== 'openai'` → 视为**未配置**（capabilities 里也是 false）并 `console.warn` 一次说明原因（Anthropic 无对应端点）。
- `TTS_TEXT_CAP = 4096`：超出截断，返回 `truncated: true`。
- `DEFAULT_TTS_VOICE = 'alloy'`；`settings.ttsVoice` 覆盖。
- 文件对象用 `toFile(audio, \`audio.${ext}\`, { type: mimeType })`（`import { toFile } from 'openai'`）。

```ts
    // GET /api/voice — 能力探测(前端据此显隐按钮)
    if (method === 'GET' && path === '/api/voice') {
      if (!isAuthed(req)) return sendJson(res, 401, { error: { code: 'unauthorized', message: 'Not authenticated' } })
      return sendJson(res, 200, deps.voice.capabilities())
    }
    // POST /api/voice/stt — 音频 → 文本
    if (method === 'POST' && path === '/api/voice/stt') {
      if (!isAuthed(req)) return sendJson(res, 401, { error: { code: 'unauthorized', message: 'Not authenticated' } })
      let body: { audio?: unknown; mimeType?: unknown }
      try { body = (await readJsonBody(req, AUDIO_BODY_CAP)) as typeof body } catch (e) {
        if (e instanceof PayloadTooLargeError) return sendJson(res, 413, { error: { code: 'too_large', message: '音频过大(上限 25 MiB)' } })
        return sendJson(res, 400, { error: { code: 'bad_request', message: 'invalid body' } })
      }
      if (typeof body.audio !== 'string' || typeof body.mimeType !== 'string') {
        return sendJson(res, 400, { error: { code: 'bad_request', message: 'audio(base64) 与 mimeType 必填' } })
      }
      try { return sendJson(res, 200, { text: await deps.voice.transcribe(Buffer.from(body.audio, 'base64'), body.mimeType) }) }
      catch (e) { return sendVoiceError(res, e) }
    }
    // POST /api/voice/tts — 文本 → 音频字节
    if (method === 'POST' && path === '/api/voice/tts') {
      if (!isAuthed(req)) return sendJson(res, 401, { error: { code: 'unauthorized', message: 'Not authenticated' } })
      let body: { text?: unknown }
      try { body = (await readJsonBody(req)) as typeof body } catch { return sendJson(res, 400, { error: { code: 'bad_request', message: 'invalid body' } }) }
      if (typeof body.text !== 'string' || !body.text.trim()) {
        return sendJson(res, 400, { error: { code: 'bad_request', message: 'text 必填' } })
      }
      try {
        const { audio, contentType, truncated } = await deps.voice.speak(body.text)
        res.writeHead(200, { 'content-type': contentType, 'content-length': audio.length, ...(truncated ? { 'x-zuse-tts-truncated': '1' } : {}) })
        return res.end(audio)
      } catch (e) { return sendVoiceError(res, e) }
    }
```
